# E.V. Solar review — 5 September 2026

Baseline: `66d62e6` (main, latest dashboard performance and vehicle-status
changes).

## Scope and architecture

Reviewed the recent Git history, React dashboard/navigation/vehicle cards,
energy attribution, charging-controller architecture and safety regression
tests, Solar.web Wattpilot import, schedules copy, history/statistics tests, and
GitHub validation/build pipeline. Existing discussions reviewed: Réviser EV
Solar GPT ASTRE, Améliorer la page d’accueil, Afficher statut charge cartes,
Revue fonctionnelle EV Solar, Analyser EV Solar et ChargeHA, Analyse régulation
Solar. This is the available conversation context, not a complete account-wide
archive.

The architecture remains appropriate: a pure shared ControllerEngine, server
orchestration and adapter commands, plugin integrations for Fronius and Tesla,
SQLite repositories, and a React/tRPC client. No database migration, production
configuration, credentials, charging commands or history deletion is included.

## Corrections, in impact order

1. Vehicle telemetry now takes precedence over the selected Stop mode. A vehicle
   still reporting charging shows its power and an awaiting-confirmation
   message. Away vehicles no longer show home Solar/battery waiting states.
   Charging is consistently green, connected blue, waiting amber, disconnected
   gray, errors red; the selected charging mode retains its own separate color.
2. Solar.web Retry-After values longer than five minutes are no longer silently
   shortened. The import fails explicitly with the requested wait duration
   rather than sending premature retries. Existing short quota retry behavior
   remains.
3. Home, Stats, Schedules and Settings remain visible on mobile. Navigation and
   the brand home action use keyboard-accessible buttons; the burger exposes its
   expanded state. The temporary preview was checked at 390 and 320 px widths.
4. The home status uses readable kW values, including unavailable-power
   handling.
5. The header's broken PNG reference is replaced by the existing approved WebP
   artwork, with light/dark variants. The artwork itself is unchanged.
6. CI validates formatting without rewriting files first and uses Deno 2.9.6,
   matching the locally tested runtime. Existing formatting debt was normalized
   locally so the stricter check can pass. Changes outside the functional areas
   above are formatting only. The wizard lazy-load test now allows five seconds
   under a busy full-suite run instead of the one-second default; its assertion
   is unchanged.

## Existing protections retained

- Solar starts at the vehicle minimum (5 A in Tesla regressions), then resumes
  surplus regulation without the steady-state debounce holding the minimum.
- Unavailable home energy data prevents unsafe increases; regression tests cover
  the safe minimum behavior and stopping conditions.
- Home energy attribution requires a positively confirmed home location;
  charging away is excluded from home Solar/Battery/Grid flows.
- The home has no GPS map, EDF logo or LIVE badge. Home-location maps remain in
  Settings and onboarding. All four charging modes are directly visible.
- Schedule copy describes Smart schedules and Solar behavior. Indexed history
  queries and lazy-loaded Stats/Settings from the previous changes are retained.

## Validation and limits

Targeted UI, controller and Solar.web tests passed before the complete checks.
The complete local pipeline covers formatting, lint, type checking, unused-file
and dependency-metadata checks, server/plugin/shared tests, and client tests. A
production frontend build is also checked. GitHub CI is the final independent
validation after push; its result is reported with the pull request.

No real Fronius GEN24, BYD HVS, Tesla or Raspberry Pi hardware was exercised.
Tests use simulated telemetry and API responses. The temporary visual preview
used the actual UI components with synthetic data, without a live backend.

Remaining follow-ups:

  icon-192-exact.png used by the PWA manifest and apple-touch-icon.png. The
